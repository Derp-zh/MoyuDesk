# H01 提示气泡

现行规则，2026-11-04由用户确认。提示气泡是短时操作反馈，与通知监听、悬停说明分别归类。

- H01-01：绑定会话结果、“至少保留一个运行中的阶段”等操作提示共用同一提示气泡模块，显示4秒后消失。新提示替换旧提示并从本次显示重新计时，不叠出多条。
- H01-02：保持既有当前屏幕工作区水平居中、62%高度的位置，固定屏幕坐标，不随来源控件漂移。所属窗口关闭／隐藏时及时清理，不等待满4秒。
- H01-03：不添加系统默认淡出造成额外停留；计时器及来源事件在关闭时解绑。未连接控件安静跳过，不以通用错误窗代替气泡。
- H01-04：提示不改变任务字段、绑定结果或保存规则；成功、取消及失败反馈按各自真实结果显示，剪贴板未确认恢复等重要信息不能在失败分支被隐藏。

实现入口为Ui.Hints.cs。验收覆盖4秒到期、新消息替换、来源隐藏、固定位置和资源清理；真实桌面显示与离屏检查分别报告。
