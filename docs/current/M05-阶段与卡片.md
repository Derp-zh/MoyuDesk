# M05 阶段与卡片呈现

现行规则，核对日期2026-11-12。

## 阶段与可见内容

- M05-01：默认阶段0，新阶段递增编号，创建编号与名称、展示顺序独立，改名不影响后续编号。可独立改名称/详情；“＋新阶段”在左侧。阶段名右邻圆形X删除阶段，其右侧圆形↕手柄按住拖动排序；新建和编辑均提供，拖动时显示跟随影像，其他阶段实时让位呈现候选顺序；松开有效位置后才改副本，保存后提交；删除仍先改副本。排序以准确阶段ID移动整个阶段，保留详情、会话和运行标记，不重排创建编号。Esc快速轻按、右键、丢失捕获或无效落点取消，取消不提交预览顺序。只剩一个阶段禁止删除；唯一运行阶段沿用至少一个运行中的保护，使用M05-04同一气泡模块。删除不影响剩余阶段输入和会话；不新增富文本或附件。
- M05-02：每阶段独立“运行中/未运行”，可多阶段同时运行且至少一个运行。新任务阶段0默认运行；点击“＋新阶段”后自动将键盘焦点移至新阶段详情输入框以便直接输入，新阶段初始状态支持在设置中三选一：选项A（默认）灵感库/完善中任务编辑及所有新建任务默认未运行、其余（如进行中任务编辑）默认运行中，选项B全部默认运行中，选项C全部默认未运行。旧任务原当前阶段迁为运行、其他未运行。旧唯一当前阶段不控制新显示/汇总。切换仅改变看板标记，不向Codex发启动/暂停。
- M05-03：编辑器中切换保存后提交；列表切换立即生效并可撤销。阶段/详情提交不覆盖后台最新会话状态与其他入口新改的运行标记；合并、旧文件、撤销也保证至少一个运行阶段。
- M05-04：最后运行阶段不可关闭，不新增撤销记录、不联动开关编辑；显示“至少保留一个运行中的阶段”提示气泡，与绑定会话结果共用提示气泡模块，显示4秒后消失。当前屏幕工作区水平居中、62%高度，无额外系统淡出。未连接控件安静跳过，不弹通用错误窗口、不跟随锚点漂移。
- M05-05：多阶段任务卡片展示全部运行阶段，不限制四项、不展示相邻暂停阶段；各列表适用，包括灵感库的多阶段任务。所有阶段数据保持。单阶段列表卡片不显示阶段名及状态图标，详情/会话名按既有例外显示。灵感库会话及状态图标例外见[M06](M06-灵感快捷录入.md)。不得用隐藏阶段详情生成空名称任务的可见标题。
- M05-06：列表暂停某阶段后立即生效，本次显示暂留整块并变暗，重开运行立即变亮；阶段切换本身不整理暂留。之后任何任务的新建、打开/关闭编辑、保存、拖动、删除、归档/取消、撤销/恢复等明确人为操作统一整理全部任务；下次球/快捷键展开也整理。输入暂存、后台消息、自动流转不整理。缓存不持久化，重启按真实标记显示。
- M05-07：整理暂留阶段约180ms向上裁切收起，无窗口泛光白条；删除/归档整卡同样收起后移出。自动归档可收起对应整卡，不整理其他任务。未显示卡片直接刷新，不为动画滚动列表。
- M05-08：运行图标为两个静态竖矩形暂停符号，未运行为三角；新建/编辑内三角单独降低亮度。列表只显示可点击图标，新建/编辑使用24DIP小圆按钮和原图标、不显示状态文字，以提示和辅助名称说明状态；阶段名称圆角胶囊整体即为单一拉满（最小64DIP、最大155DIP）的`TextBox`输入框且文字纵向居中；归档预览只读；图标点击不触发任务编辑开关。

## 外观与名称行

- M05-09：任务标题加粗青色并带青色细竖条，正文白色。卡片内部纵向留白为原3/5（上下11→6.6、文字4→2.4），横向间距、卡片间距保持；阶段名12、阶段详情14，已移除的相邻阶段摘要不继续作为字号分支。底部仅平台和优先级胶囊，不重复摘要。阶段分隔线灰色，标题与阶段间为青色；共用一物理像素、同宽对齐，线本身不增布局高度。青线到首气泡留白与气泡到其下正文实际字形间距对齐。
- M05-10：名称行从右至左预算状态图标、会话名称、左侧阶段气泡。会话用实际继承字体3至5个“中”字宽，不按编码字节或大写M计宽；不足3字宽保留3字，超过5字滚动，短文本靠右。未绑定显示“未绑定”，灵感库隐藏会话名例外不变。
- M05-11：阶段气泡短名自然宽、左对齐，没有字符最小宽度；上限是扣除右侧图标/会话及原间距后的全部余宽。极窄时文字、边框和内边距一起裁切，不侵入右侧控件。列宽变化时同一卡片同步重算，右侧保持右锚。
- M05-12：所有溢出滚动文字首停1秒，24DIP/秒单向慢滚，末停0.5秒，复位循环；无溢出不滚。球/快捷键展开从头，收起冻结，隐藏停止计时，滚动偏移不持久化。不显示冗余Codex状态行，关联数据仍保留；不可见且不影响跳转提醒颜色的执行状态变化不重建卡片。

- M05-14：独立列表阶段详情至少两行，空和一行均保留两行高度；“省略多列表阶段详情的超出文本”默认开启，按当前可用宽度下的文本总行数等比例自适应省略（4行及以内完整显示不省略；超过4行按 `round(totalLines * 0.4)` 钳位至3–10行且严格小于总行数），末行末尾（避开右下角跳转会话图标）以紧凑圆角气泡按钮 `[…]` 替代静态省略号，点击原地展开全部内容并持久化记住展开状态（关闭面板再打开或重启程序保持展开），展开态末尾提供紧凑收起气泡按钮 `[▴]` 点击恢复省略并移出记忆；气泡点击不触发卡片编辑或拖动；关闭该设置后完整显示并随内容增高；列标题窄列单行截断显示省略号。普通多列表与专注模式鼠标滚轮统一采用固定舒适像素步距（80 DIP/格，且不超过当前视口高度的25%），保留90ms缓动动画。新建/编辑中的“运行中”阶段正文至少两行且默认始终完整展开（不设180高度上限、不因失焦自动收起）；默认“未运行”阶段空白及短正文至少1行，有内容最多1行并显示省略号，切换运行状态以180ms连续展开/收起，快速反向不丢完整正文。设置“未运行阶段的详情只显示一行”独立默认开启，关闭后未运行也展开至少两行；设置即时更新已开编辑而不重建其输入。未运行详情输入获取编辑焦点或打开右键菜单时，自动完整展开并解除高度上限（点击展开瞬间抑制初始拖拽误选多行），以窗口外层滚动阅读编辑全部内容；点击阶段详情自身底部区域不误收起，点击输入框外空白可正常退出焦点。焦点引起的高度变化同样采用180ms展开/收起动画，保留完整内容及最后字符。两个偏好相互独立并持久化。排序手柄图标使用1.5线宽柔化配色的单次填充合并轮廓，悬停不改变鼠标指针样式（保持默认箭头）且圆形边框亮起青绿色高亮（`AccentBrush`）。
- M05-15：详情文本范围内右下角提供一行高的“跳转至会话”图标按钮，无圆形勾边；只在最后一个显示行右侧为图标让位，上方各行保持完整宽度；完整展示时重新换行，省略时末行同时为省略气泡与跳转图标让位，不覆盖文字。当任务及其所有阶段均未绑定任何有效会话时，卡片不显示“跳转至会话”按钮且末行文本不让位；有绑定时保持原样（含同卡另一阶段已绑定的未绑定阶段）。绑定会话尚未被本地确认的待处理事件导致内置待操作时，仅对应运行阶段图标橙红；左键点击跳转至会话且跳转成功后，自动消除该阶段及同一会话所有绑定阶段（#12联动）的橙红提醒（跳转失败不误消），卡片继续留在“待操作”列不变；手动移入进行中确认当前事件，真实执行清对应橙红，后续新请求重新提醒；时间提醒或普通人工待操作不冒充会话等待。球待操作预览沿用同一逐阶段按钮，详见[M09](M09-搜索与会话选择.md)。右键单击图标仍可按该阶段当前事件身份单独确认橙红，不移列/跳转/清时间红点或其他阶段提醒；多个阶段（含同任务或跨任务）绑定同一外部会话时，处理/消除其中任一阶段或移回进行中后，所有绑定该同一会话的阶段橙红同步消失；主侧来源聚合在所属阶段，下一事件仍可提醒。
- M05-16：任务卡片存在未读定时提醒红点时，鼠标悬停红点区域弹出紧凑提醒预览气泡，仅紧密排布提醒时间与“关闭提醒”按钮两段信息（#22方案A），并以80ms屏幕坐标轮询检测红点、气泡及过渡通道，鼠标移出约120ms后自动关闭、窗体隐藏或卡片卸载时立即关闭，杜绝常驻不关。点击卡片、Locate定位、打开编辑或保存未改动提醒的编辑均不误消提醒红点；仅在显式点击“关闭提醒”、右键“已查看提醒”或在编辑中重设/关闭提醒时清除红点。

专注模式的卡片宽度随窗口可用区域分列，逐行从左到右，单卡内容、阶段按钮、详情省略/跳转及绑定手势保持；拖动占位按行及横向位置判断，未显示的远端卡片按视口虚拟化生成。普通模式仍为原单列虚拟面板。

## 验收

- M05-13：普通启动默认提供阶段会话名称拖动绑定，未绑定也可拖；仅名称区域接管该手势，整卡拖动、阶段开关、名称宽度、灵感库例外及归档只读保持。拖出来源列后临时隐藏其他原可见列，结束或取消只恢复这些列表。详见[X01](X01-拖动绑定探索.md)；未取得准确编号不改绑。
阶段删除覆盖新建/编辑、仅剩一阶段、唯一运行阶段、阶段0删除后的有效指针和实际落盘、取消保存、撤销恢复、剩余阶段输入/会话及晚到后台等待；X在阶段名右邻，复用原固定位置气泡。离屏事件与物理鼠标分别报告。

覆盖至少一个运行、多运行、暂停暂留/全局整理、后台不整理、单阶段/灵感例外、归档只读、同一卡片窄宽变化、3/4/5/6中文及英文混合会话名、短/长阶段名和双文本滚动。分别检查实际保存的阶段、图标操作和任务卡片操作，不能只测提交前副本或重复认可同一错误宽度。
