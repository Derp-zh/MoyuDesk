# M07 卡片操作、撤销与归档

现行规则，核对日期2026-11-13。

- M07-01：卡片左键正常点击打开/切换对应编辑，会话名称文本区域的普通单击也执行同一编辑动作；阶段运行等专用按钮仍优先执行自身动作并打断外点序列。按下移动超过拖动阈值才拖动，会话名称处拖动绑定会话，其余原卡片拖动区域仍用于跨列／排序，拖动完成或取消不补发编辑单击。列表空白/标题双击行为见[M04](M04-新建编辑与草稿.md)。
- M07-02：任务卡拖动采用手机文件夹式空位传播：源卡退出展示序列，整组仅有一个目标占位，同列/跨列/网格按行阅读顺序让邻卡填入旧空位。占位内保留阈值，指针停留不反复翻位；边缘停留持续滚动，未实现的远端后继按逻辑序列判断。不同卡高按行最高值排布并保留测量缓存。只在开始生成一次跟随图，数据及持久顺序仅有效松手提交；Esc、非法落点、退出/隐藏取消清占位、恢复当时真实顺序，不回滚后台合法变化。完成时间排序的占位服从完成时间规则。跨窗缝不误收起，窗体拖动/卡拖动/文字选择保持区分。
- M07-03：撤销/恢复为本次运行最近20步，覆盖删除、跨列移动、排序、已提交字段、列表阶段运行标记。输入不计步，无20秒限制；新正式操作清恢复分支。历史重放不得覆盖后台AI/提醒。归档/取消归档走专用入口，不借撤销重放淘汰数据。
- M07-04：所有独立列表的活动任务卡片右键均同时提供“删除任务（可撤销）”和“归档任务”，涵盖全部内置身份及自定义列表。已有任务编辑窗口的“归档任务”先保存当前编辑再归档，写入失败保留活动任务及输入。归档完整阶段/排序/编号，移出活动列表、停止后台处理并清对应撤销引用；普通删除不产生归档，归档走专用恢复入口。
- M07-05：设置归档页首次构建最近20条预览，可加载全部；重入或真正重开设置恢复20条，预览数量不等于存储上限。取消归档恢复相同任务身份、完整阶段及保存后的目标列表，未经归档编辑时用原列表；已删目标列表恢复相应角色。保留Codex编号，但重置代次、实时信任及等待保护。
- M07-06：已完成超过天数自动归档默认开启，默认5天，可填1至36500整数；从进入已完成计时，严格超过整天数才归档。编辑不重置、离开清除、再进入重计；缺计时仅初始化当前时间。运行约每分钟和启动检查，有未提交编辑副本先保留；关闭则不自动归档。
- M07-07：“只保留最近40条归档”默认关闭，关闭不按数量淘汰；开启超40时先说明实际永久删除数量，经界面确认才开启并删除，以后维护保持40条。不可撤销找回已淘汰归档。
- M07-08：人为删除/归档可等待180ms整卡上拉收起再移出。后台AI/提醒的自动移列则先提交真实状态和保存通知，再播放移出上拉/移入下拉，不能等动画完成才保存；隐藏仅更新，快速反向无重复/零高残留。

- M07-09：归档页任务可单击打开正常编辑窗口，左上角提示“已归档”，字段可编辑并沿用验证／保存／取消语义；保存后仍在归档，不启动活动任务的后台监听。修改当前状态后，取消归档按保存后的状态／准确列表恢复，原归档时间及原来源历史保留。归档编辑支持撤销／恢复，取消归档重置信任及等待保护，不把归档编辑撤销为活动任务。
- 归档编辑须显示在发起它的设置窗前并接收输入，取消归档后恢复普通编辑层。0.9.42修复及实际命中/保存证据见[桌面验收](../ACCEPTANCE-DESKTOP-0.9.42.md)。
- M07-10：归档页使用显式“归档规则／已归档任务”分区，正常错误行不占位；天数与自动归档开关联动，提示简短。归档记录采用紧凑标题、阶段数和可选单行详情摘要，空详情不占位；不沿用活动列表至少两行的正文或禁用跳转图标。日期、来源、“取消归档”胶囊及24DIP圆形X均位于同一张卡片边界内，底部单行对齐，长来源省略可看提示；正文单击仍打开完整归档编辑，操作按钮不触发正文编辑。X永久删除前确认；取消不改数据，确认只作用于原确认记录，不作用于已切换数据或替换记录。删除清对应编辑及撤销引用，不能通过活动任务撤销重建；20条预览/加载全部及自动淘汰规则保持。

- M07-11：内置已完成独立列表“已完成按完成时间从早到晚排列”默认开启，按进入已完成的CompletedSinceUtc升序显示；仅编辑不改该时间，离开后再进入重新计时。旧任务缺完成时间由原完成计时初始化逻辑补齐。仅显示排序，不改写原手动任务序列；关闭后恢复手动序列。专注模式展开的已完成沿用此规则，普通自定义列表即使改名已完成也不冒充内置角色。

验收：完成时间升序/关闭恢复手动顺序/编辑不重排/移出再移入及重启回读；点击与拖动区分、跨列/排序/取消重启回读、20步撤销/恢复与后台交错、归档/取消、默认5天严格边界/编辑不重计、未提交副本保护、20条预览/不限存储/40条确认、动画取消，以及归档空态/长标题/620和760宽度的紧凑布局与真实点击。

依据：R46至R49、D06、U31/U50/U51/U53/U93/U118/U119/U122至U124/U178。
