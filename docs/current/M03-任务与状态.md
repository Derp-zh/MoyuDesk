# M03 任务数据与状态

现行规则，核对日期2026-11-09。

- M03-01：区分草稿/已建任务、所在列表、AI执行状态。“已建”不等于位于进行中；阶段不等于列表。默认六列角色见[M02](M02-列表与布局.md)。
- M03-02：任务、阶段及列表身份稳定，改名、布局变化、跨列或未来同步不改变编号。保存顺序、字段选项引用、阶段运行标记及阶段会话绑定。
- M03-03：草稿不出现在正式列表、正式搜索、待操作预览和提醒中。名称或任一阶段详情含非空文字才有内容；仅阶段名、字段选择、新增空阶段不算。正式任务可只填详情，名称空时以允许展示的详情首行生成标题，不强制补名称。
- M03-04：任务当前状态与实际所在列表一致，自定义列表保持独立身份。跨列提交顺序，取消不改变；归档移出活动列表，普通删除不产生归档。
- M03-05：已绑定AI状态只能驱动内置进行中/待操作，其他四类及自定义列保持人工归类；AI正常结束、失败、停止不自动设为已完成。用户将卡片跨列移入内置进行中，或在编辑窗口修改为该状态并保存，确认所有阶段当前待处理事件，保留来源真实等待记录；同一事件跨采样/重连/重启不再移入待操作或染橙红，同轮新请求及下一轮新提醒仍生效。来源真实执行清除对应待处理，多阶段其他未确认等待仍优先。
- M03-06：正式任务编辑只合并用户修改的字段；未修改的后台状态、提醒发生记录和阶段运行标记不能被旧编辑副本覆盖。具体提交边界见[M04](M04-新建编辑与草稿.md)。
- M03-07：旧数据读取需保持身份、阶段与关联，先备份；`preserved-data`不自动导入或删除。旧唯一当前阶段只用于迁移兼容，不重新作为新规则控制显示或流转。

- M03-08：AI平台监听提供“会话开始执行时自动新建任务”，默认false。只对已连接Codex/DSH/Claude被动读取已有本机结构记录，先建立历史基线，之后未绑定会话出现真实新执行才按准确编号/名称建立进行中任务。Codex除新轮次外，也识别准确等待后同轮继续执行（含前台待处理后立即最小化）；持续运行中的普通推理片段不重复建卡。活动任务及草稿绑定去重；候选先保存，再进入活动列表；执行水位随任务数据持久化，轮询、并发、删除及重启不重复建卡。关闭、配置/数据切换丢弃迟到结果；未知/损坏来源不猜，单会话错误不阻塞其他会话并自动重试。回答或批准本身不是执行。 Codex侧边聊天按结构化父链归到主会话，同一主绑定聚合运行与等待，自动候选按主UUID去重，侧边不独立建卡；旧基线不重放，可信发现的准确执行证明仅运行期保留，用于首次观察前已结束的侧边。

验收：空内容、详情独填、草稿排除、跨列/自定义列、旧数据隔离读取、编辑与后台交错合并、重启回读。迁移正式数据需用户明确授权。
