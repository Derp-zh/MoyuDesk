# M10 时间提醒与待操作预览

操作提示气泡已独立归类，统一时长及生命周期见[H01提示气泡](H01-提示气泡.md)，与本页时间提醒及Windows通知分别处理。

现行规则，核对日期2026-11-27。

- M10-01：提醒以高频“一次性临时定个点”为主，同时支持每天、每周；“定时提醒”整行标题文字与22DIP勾选圆均可直接切换开关，键盘操作保留。草稿只存配置，正式保存后生效；收起、球隐藏继续，退出停止。
- M10-02：提醒到期时，卡片严格留在原本所在列表的原位不动（不再将暂搁置、灵感库、完善中、进行中或自定义列卡片自动移入“待操作”列），仅在原位亮起醒目红点、记录“定时提醒到期”原因并发出一次托盘轻提示（“N项任务定时提醒已到期。点击查看。”）。同一次到期不重复，休眠/重启错过多个周期只补一次并推进；已完成停止提醒。时间和AI待处理原因分开保存，不相互覆盖。
- M10-03：AI可信实际恢复且整卡从待操作回进行中，同时清时间红点。只回答/批准、单请求消失、idle/未知、重复运行快照、另一阶段仍待处理都不算整卡恢复，不清点。点击卡片、Locate定位、打开编辑、移动卡片、切换阶段运行或保存未改动提醒的编辑均不误消提醒红点；仅在用户显式点击红点悬停预览框内的“关闭提醒”气泡按钮（#22方案A）、右键点击“已查看提醒”或在编辑框内关闭/重设提醒并保存时才消除红点。红点悬停预览窗紧凑仅显示提醒时间（如 `今天 15:30` / `11月21日 15:30` / `每天 09:00`）与“关闭提醒”按钮两段内容，并以80ms屏幕指针轮询（覆盖红点、气泡及通道）确保移出约120ms内关闭且窗体隐藏/卡片卸载即关。点击气泡“关闭提醒”清除红点、移除“定时提醒到期”原因并关闭该任务定时提醒（可撤销）。
- M10-04：面板收起悬停球，上方预览只显示待操作正式任务的名称、阶段详情、平台、优先级，不显示旧“当前/前一/后两项”的相邻阶段摘要；宽198DIP，换行可滚动，无任务空状态。当前源码按BoardEngine.CardStages取得运行阶段详情。球、预览及两者通道共同保持悬停，离开完整区域后延迟收起，不永久驻留。
- M10-05：预览每个显示阶段提供正文右下角一行高“跳转至会话”（当任务及所有阶段均未绑定任何有效会话时不显示），未绑定阶段（同卡他阶段已绑时）禁用，实际等待阶段橙红；点击只跳对应聊天，不触发外层任务定位。其余区域点击仍展开并定位任务，展开后隐藏预览，菜单/预览使用期间不边缘隐藏。球到预览的悬停通道及离开延迟保持；基础文档400ms为建议值，不在此升级为确认。

- M10-06：新建任务默认提醒与从未勾选切换为勾选开启定时提醒时，自动按操作当下时间对齐**当前日期及下一个小时整点**（如 `03:40 → 当日 04:00`、`14:00 → 当日 15:00`、`23:40 → 次日 00:00`，星期同步对齐）；已开启定时提醒的任务打开编辑窗口时严格保留原保存日期、时间与星期，绝不覆盖。提醒日期可直接输入或打开原生日历，提供今天/明天；时间为24小时制，可直接输入任意分钟，时间选择弹窗采用小时（00—23）与分钟（00—59）各自独立的滚动选择列表，直接点选即时更新生效（废弃旧24小时方格矩阵二步确认）。一次提醒有15/30/60分钟后快捷项，按点击时刻计算，跨日正确。每天/每周隐藏无关日期，继续原ReminderClock调度。
- M10-07：输入中的原文字与合法提醒值分离；空白、非法时间及日期不得兜底今天或旧值后误保存。失焦/Enter/保存给出错误，正确提交标准化HH:mm；支持Tab、Alt+Down、Esc、上下键分钟调整（Shift小时）。弹层近场展开并避开工作区边缘；关闭、隐藏及编辑切换清理弹层。

验收：直接输入/日历/小时分钟/键盘、非法字段拦截/取消、闰日和跨日、保存失败与实际回读，以及每天/每周/一次、草稿排除、收起到期、错过多个周期、已完成停提醒、红点与多阶段/重连/编辑交错、球到预览通道和点击定位。红点需实测整卡与保存结果，不能只验证单阶段事件。

依据：R60至R67/R85至R87、D10/D11/D12最新有效部分、U07/U35/U78/U173/U174/U178/U186。
