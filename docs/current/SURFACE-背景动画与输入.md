# 共享规则：背景、动画、输入与窗口层次

现行规则，核对日期2026-11-13。所有窗口类改动先查[共享代码影响表](../architecture/SHARED-CODE.md)，不能以外观一致代替交互一致。

## 背景与输入

- S01：实时暗色透明毛玻璃，模糊与透明度分别有效，系统不支持明确降级。列表默认20%、球40%、新建/编辑/设置等悬浮窗口独立默认10%，可设0%至100%，旧配置缺字段采用对应默认；保存/重启/配置导入/路径切换保持。新建与编辑遵循同一悬浮透明底色。
- S02：真实背景随下层画面变化属于正常行为；不得缓存桌面截图作毛玻璃，不通过移动后隐藏重显整窗刷新。虚线入口透明无毛玻璃底板。圆角输入、按钮、菜单/下拉为圆角矩形或胶囊，系统原生文件框遵循系统外观。
- S03：透明输入区域保持系统命中及内部控件命中。列表根保留全区非零alpha输入表面（当前实现alpha1）；球形状/矩形扩展/透明角/隐藏条带必须与可见范围一致。内部370画布不等于外部可点370。不得只测WindowFromPoint或直接触发Click。
- S04：所有窗口滚动条细亮且激活/失活/悬停不变；列表原尺寸约6DIP，悬浮竖滑块、轨道及横向内缩为原1.34倍，抽牌快照继承。滚轮90ms缓出，连续接续/反向中止；列表虚拟化、原轮距、拖动边缘逐卡保留，直接拖滑块、点击/键盘/定位不被惯性抢回。
- S05：保存输入保护拦重复动作/键盘/输入法/粘贴，不用Root.IsEnabled=false导致整体变暗。第一次外点保持、第二次按[M04](M04-新建编辑与草稿.md)处理，不重建内容/重播/重置背景。

## 开合、抽牌及生命周期

- S06：六列、新建、编辑、设置等普通开合为真实控件原生范围裁切，内容固定不随窗体平移，不截图交接；目标100ms。冷首帧准备后，各参与者登记启动回调，由同一次Normal队列回调同步放行；不能让最后到达者在Render中内联启动、其他Input续体延后。外点与球点击复用同一屏障，准备超时仍释放；代次取消和快速反向保持。忙碌掉帧是已接受取舍，不承诺所有环境120FPS。
- S07：仅从中心展开/收起的悬浮窗具有中央全高细白芯及两层泛光，与内容共用进度，开合亮度/宽度连续，快速反向接续当前位置但仍播放完整100ms，每次重开重新触发白条。侧向展开的绑定会话专属窗口、专注模式已完成窗口、球，以及上下裁切的卡片/阶段不显示中心白条；绑定窗左右翻侧均适用。重复调用已打开窗口不重播；中心白条不得被层次遮挡，不用漏采帧冒称实际缺失或已正常。
- S08：球开合按所在位置选择朝左或朝右，固定370DIP真实内部画布（极窄工作区限制可见宽），外部原生范围58至370；父轮廓与子窗口按对应侧锚定同步，展开准备期即保持搜索栏可见且不随 `Width>64` 突跳透明度、`LiveBackdrop` 区域仅做偏移更新而不逐帧销毁重建、`SetWindowPos` 配合 `SWP_NOCOPYBITS` 并同步更新 `WindowRgn` 与子画布，避免搜索框闪烁；命中换算到可见坐标，100ms和快速反向保持。左右边缘吸附隐藏保留100ms位移，不与开合裁切混淆；贴屏边平直且原生裁切不泄漏至相邻屏幕。
- S09：草稿抽牌仍保留合成预览及[M04](M04-新建编辑与草稿.md)的1.35倍路径/2/3门槛，不以普通开合取消截图为由删抽牌。快照不与真实内容重叠产生加深/闪烁。普通开合中最后草稿结束才清控件，快速重开取消旧清理；旧回调检查代次/句柄，真正关闭释放内容宿主。
- S10：编辑/新建/设置高于列表，球最高；点击列表不压住编辑，整组恢复保留编辑/草稿原输入和前后顺序，主动关闭的不恢复；设置不加入整组恢复，需手动重开，但本进程保留细分设置页。所有 `SurfaceWindow` 保持工具窗样式不进任务栏，由唯一主宿主代理窗口代表本程序出现在任务栏与 `Alt+Tab`：`Alt+Tab` 切到其他应用时收起到悬浮球，`Alt+Tab` 切回本程序时自动展开打开多列表独立窗口（关闭内部弹窗/拖动/对话框/IME 与切换器浮层预览期间不误收起），不影响全局快捷键。真实外部鼠标按下与外部前台切换可收起面板，点击第三方或系统输入法（微软拼音/TextInputHost、搜狗、QQ拼音、Rime/Weasel 等）候选词框或状态栏时完全免疫不收起也不关闭内联输入。全屏游戏补充原始鼠标输入（修复 32 位 tick 跨零回绕与区域限位指针检测）并结合合法前台切离事件收起面板，与钩子去重、不吞输入、不改游戏配置；不能以模拟测试声称具体游戏通过。
- S11：卡片/阶段删除和暂留整理180ms上拉；后台自动进行中/待操作移列先状态及保存再播放退出/进入，隐藏不播。取消/反向须恢复可见尺寸和输入，不残留重复卡片；动作边界见[M07](M07-卡片操作与归档.md)。长文本任务卡片采用 `StageDetailsText` 省略预截断与布局缓存、`TaskCardLayout.DetailsInkTop` 缓存、`StageDetailsEditor` 收起态跳过全量测量与尺寸缓存、`AdaptiveCardPanel` 增量更新与轻量拖拽占位、`TaskCard` 无 JSON 结构快照以及 `Copies.Of/Same` 快速深拷贝，保证打开、保存与拖拽流畅。

## 必查场景

背景/透明度修改分别验证新建及编辑的首开、重开、设置变化、多草稿与抽牌；同背景黑/白/细纹理对照检查透底与模糊，展开后至少1至6秒采样，遮挡/通知等异常帧保留。延迟突然变深根因仍未确认，不把正常实时变化当bug。

列表共享层必须覆盖空白右键、标题拖动、22×22整组缩放、单列缩放、卡片、新建全轮廓及滚动条；球形状覆盖新增矩形左右键、拖动和菜单位置。关闭闪烁分别看首次打开、第一次外点、第二次保存/暂存、关闭开始/结束，包含改动编辑、关联区展开、正在保存及快速重开。实际占用桌面输入、切换前台或临时使用剪贴板前，按根AGENTS.md先询问用户是否方便，收到明确同意后才开始；仅提示不能代替确认。
