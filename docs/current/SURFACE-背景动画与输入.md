# 共享规则：背景、动画、输入与窗口层次

现行规则，核对日期2026-11-27。所有窗口类改动先查[共享代码影响表](../architecture/SHARED-CODE.md)，不能以外观一致代替交互一致。

## 背景与输入

- S01：实时透明毛玻璃底色与 DWM 深浅窗体属性（`DwmSetWindowAttribute(20)`）随当前主题调色板（`ThemePalette.Current`，默认深夜青蓝 `#192333`，支持 5 套深色 + 4 套浅色预设及跟随系统实时切换）即时联动，模糊与透明度分别有效，系统不支持明确降级。列表默认20%、球40%、新建/编辑/设置等悬浮窗口独立默认10%、待操作列常驻穿透默认70%，均可设0%至100%，旧配置缺字段采用对应默认；保存/重启/配置导入/路径切换保持。当透明度设为 0%（100% 不透明）时，同架构内跳过挂接系统 `HostBackdropBrush` 桌面实时模糊采样层，直接以当前主题实心底色 `CompositionColorBrush` 绘制以节省性能，不销毁重建窗口；调回 >0% 时平滑恢复模糊。新建与编辑遵循同一悬浮透明底色。待操作列开启常驻穿透时对母子句柄施加 `WS_EX_TRANSPARENT` 并在 `WM_NCHITTEST` 返回 `HTTRANSPARENT`，同时在“常驻”图钉按钮上方同步置顶轻量无穿透解除浮窗（`WS_EX_TOOLWINDOW`）保障局部可点。
- S02：真实背景随下层画面变化属于正常行为；不得缓存桌面截图作毛玻璃，不通过移动后隐藏重显整窗刷新。虚线入口透明无毛玻璃底板（圆角12DIP、悬停微亮高亮且保留非零alpha全区命中）。常规文字按钮及关闭按钮统一为利落圆角矩形（`CornerRadius=9`）并采用当前主题高对比按钮与勾选框色板（默认深夜青蓝普通底 `#E8334662` / 边框 `#5E789B` / 悬停 `#F241597A` / 文字 `#F3F7FD`，主按钮 `#96DACC` / 深字 `#0D2320`；默认白天晴昼青雾普通底 `#E8D2E1F3` / 边框 `#8AA4C6` / 悬停 `#F2C0D4EC` / 深墨字 `#152338`，主按钮 `#0D877A` / 纯白字 `#FFFFFF`；全部 9 套预设均通过 `Theme.xaml` `{DynamicResource}` 实时联动），固定正方小图标按钮保持正圆，常规输入框/下拉框统一为 `10DIP` 圆角矩形（阶段名称胶囊保持 `14DIP` 且绘制与裁切同步），迷你气泡与标签保持小胶囊造型，系统原生文件框遵循系统外观。
- S03：透明输入区域保持系统命中及内部控件命中。列表根保留全区非零alpha输入表面（当前实现alpha1）；球形状/矩形扩展/透明角/隐藏条带必须与可见范围一致。内部370画布不等于外部可点370。不得只测WindowFromPoint或直接触发Click。
- S04：所有窗口滚动条细亮且激活/失活/悬停不变；列表原尺寸约6DIP，悬浮竖滑块、轨道及横向内缩为原1.34倍，抽牌快照继承。滚轮90ms缓出，连续接续/反向中止；列表虚拟化、原轮距、拖动边缘逐卡保留，直接拖滑块、点击/键盘/定位不被惯性抢回。
- S05：保存输入保护拦重复动作/键盘/输入法/粘贴，不用Root.IsEnabled=false导致整体变暗。第一次外点保持、第二次按[M04](M04-新建编辑与草稿.md)处理，不重建内容/重播/重置背景。

## 开合、抽牌及生命周期

- S06：六列、新建、编辑、设置等普通开合为真实控件原生范围裁切，内容固定不随窗体平移，不截图交接；目标100ms。冷首帧准备后，各参与者登记启动回调，由同一次Normal队列回调同步放行；不能让最后到达者在Render中内联启动、其他Input续体延后。外点与球点击复用同一屏障，准备超时仍释放；代次取消和快速反向保持。忙碌掉帧是已接受取舍，不承诺所有环境120FPS。
- S07：仅从中心展开/收起的悬浮窗具有中央全高细白芯及两层泛光，与内容共用进度，开合亮度/宽度连续，快速反向接续当前位置但仍播放完整100ms，每次重开重新触发白条。侧向展开的绑定会话专属窗口、专注模式已完成窗口、球，以及上下裁切的卡片/阶段不显示中心白条；绑定窗左右翻侧均适用。重复调用已打开窗口不重播；中心白条不得被层次遮挡，不用漏采帧冒称实际缺失或已正常。
- S08：球开合按所在位置选择朝左或朝右，固定370DIP真实内部画布（极窄工作区限制可见宽）。展开前窗口一次性调整到 `ExpandedWidth` 并锚定原悬浮球一侧保持静止（动画帧零 `SetWindowPos` 缩放/移位、无截图交接），窗口内仅由单层胶囊裁切（`LiveBackdrop` 就地更新 `CompositionRoundedRectangleGeometry` 零重建 + `Root.Clip` 同步裁切）从 `58px` 平滑伸展，同时搜索框容器 `expanded` 前期透明占位并平滑淡入到 `1`；收起时反向平滑淡出与缩回，结束后一次性恢复 `58×58`；`WM_NCHITTEST` 按当前可见胶囊宽度精确计算边界并对透明外区返回 `HTTRANSPARENT` 不挡鼠标；100ms和快速反向保持。左右边缘吸附隐藏保留100ms位移，不与开合裁切混淆；贴屏边平直且原生裁切不泄漏至相邻屏幕。
- S09：草稿抽牌仍保留合成预览及[M04](M04-新建编辑与草稿.md)的1.35倍路径/2/3门槛，不以普通开合取消截图为由删抽牌。快照不与真实内容重叠产生加深/闪烁。普通开合中最后草稿结束才清控件，快速重开取消旧清理；旧回调检查代次/句柄，真正关闭释放内容宿主。
- S10：编辑/新建/设置高于列表，球最高；点击列表不压住编辑，整组恢复保留编辑/草稿原输入和前后顺序，主动关闭的不恢复；设置不加入整组恢复，需手动重开，但本进程保留细分设置页。全程序所有 `SurfaceWindow` 保持 `ShowInTaskbar=false` 与 `WS_EX_TOOLWINDOW` 工具窗样式，不创建 `Alt+Tab` 代理窗，确保 Windows 底部任务栏绝对无窗口（仅保留系统托盘、悬浮球与全局快捷键入口）；切到外部非 IME 应用时仍自动收起到悬浮球（关闭内部弹窗/拖动/对话框/IME 与任务切换器浮层期间不误收起），不影响全局快捷键。玻璃子窗 `GlassContentHost` 与母窗在点击和文本框聚焦时同步 Win32 顶层激活、默认 IMM32 上下文与 `SetFocus(ContentHandle)`，且外层 `WM_SETFOCUS` 转发后显式置 `handled = true` 避免空壳把 TSF 文档管理器退回 `EmptyDim`；同时通过 `ComponentDispatcher.ThreadFilterMessage` 安装 `VK_CONTROL` TSF 桥接，将标准 `VK_CONTROL (0x11)` 与真实扫描码直接送达 `ITfKeystrokeMgr`，彻底解决微信输入法（WeType）/微软拼音等纯 TSF 输入法单按 `Ctrl` 切换中英文失效，同时严格保留 `Ctrl+A/C/V/Z` 常规组合键、`SettingsHotkey` 快捷键录制框、`HasFocusWithinCore() == false` 防吞 `WM_CHAR` 与 `WM_NCACTIVATE` 防白框。真实外部鼠标按下与外部前台切换可收起面板，点击国内外主流输入法（微软中日韩宿主/TextInputHost、豆包输入法含悬浮条特征放行与聊天主窗排除、微信 WeType、智谱 AI、讯飞、搜狗、百度、QQ、手心、小狼毫/Rime、PIME、Google Japanese Input、Mozc、ATOK 等）候选词框或状态栏时完全免疫不收起也不关闭内联输入。全屏游戏补充原始鼠标输入（修复 32 位 tick 跨零回绕与区域限位指针检测）并结合合法前台切离事件收起面板，与钩子去重、不吞输入、不改游戏配置；不能以模拟测试声称具体游戏通过。
- S11：卡片/阶段删除和暂留整理180ms上拉；后台自动进行中/待操作移列先状态及保存再播放退出/进入，隐藏不播。取消/反向须恢复可见尺寸和输入，不残留重复卡片；动作边界见[M07](M07-卡片操作与归档.md)。长文本任务卡片采用 `StageDetailsText` 省略预截断与布局缓存、`TaskCardLayout.DetailsInkTop` 缓存、`StageDetailsEditor` 未聚焦长阶段轻量 `TextBlock` 视口首帧展示与无缝水合（收起态 `Input` 折叠零排版）、`SurfaceWindow.LiveScroll` 消除首次空预布局与单帧准备、`AdaptiveCardPanel` 增量更新与轻量拖拽占位、`TaskCard` 无 JSON 结构快照以及 `Copies.Of/Same` 快速深拷贝，保证打开、保存与拖拽流畅。

## 必查场景

背景/透明度修改分别验证新建及编辑的首开、重开、设置变化、多草稿与抽牌；同背景黑/白/细纹理对照检查透底与模糊，展开后至少1至6秒采样，遮挡/通知等异常帧保留。延迟突然变深根因仍未确认，不把正常实时变化当bug。

列表共享层必须覆盖空白右键、标题拖动、22×22整组缩放、单列缩放、卡片、新建全轮廓及滚动条；球形状覆盖新增矩形左右键、拖动和菜单位置。关闭闪烁分别看首次打开、第一次外点、第二次保存/暂存、关闭开始/结束，包含改动编辑、关联区展开、正在保存及快速重开。实际占用桌面输入、切换前台或临时使用剪贴板前，按根AGENTS.md先询问用户是否方便，收到明确同意后才开始；仅提示不能代替确认。
