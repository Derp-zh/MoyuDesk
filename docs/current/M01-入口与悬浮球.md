# M01 入口、悬浮球与托盘

现行规则，核对日期2026-11-27。只描述当前有效要求；实现与未验收项见[当前状态](STATUS.md)。

## 有效规则

- M01-01：产品中文名“摸鱼台”、英文名“MoyuDesk”。球左键及全局快捷键切换整组展开/收起，后台进程继续运行。收起隐藏列表、编辑、草稿、设置、搜索和辅助窗口，保留输入、位置、可见窗口及层次，恢复时不重开已主动关闭的窗口；设置不自动恢复显示，本进程细分页保留。球始终可操作且位于本程序窗口上方。
- M01-02：球左键及全局快捷键切换整组；右键短按松开弹菜单，右键长按拖动，拖后松开不弹菜单。自由球可自由移动；吸附球也可跨左右拖动，松手吸附到球当前所在屏幕最近的左右边缘，不吸顶/底，位置保存完整可见球坐标。
- M01-03：球与托盘右键共用同一菜单、启用状态及原层级，保留隐藏/恢复悬浮球、设置、恢复窗口默认、撤销、恢复、展开 / 收起看板、退出，以及AI统一连接和状态子菜单；菜单背景、文字、高亮、边框及开关色彩由 `OrbMenuRenderer` 实时联动当前深浅色主题。吸附项短名“吸附到桌面边缘”，仅该行右侧绘制小开关，整行和键盘均可切换；全部菜单不保留左侧勾选/图标空列。它与常规设置即时双向同步并自动保存；退出前保存失败必须可见。
- M01-04：全程序零任务栏窗口、不创建 `Alt+Tab` 代理窗：所有列表、编辑、设置与悬浮球窗口均设 `ShowInTaskbar=false` 且带 `WS_EX_TOOLWINDOW`，仅保留系统托盘、悬浮球与全局快捷键入口；切离至外部非 IME 窗口时仍自动收起到悬浮球（保留常驻待操作列并免疫原生对话框与任务切换器浮层）。悬浮球与托盘图标全面使用官方猫咪圆标资源（`Assets/orb.png` / `Assets/orb.ico`），待操作计数红圈与边缘吸附红点位于图标上方清晰可见。检测球所在屏幕可用工作区，启动/显示/移动结束/配置切换/屏幕或DPI变化更新方向和边界，避开任务栏。靠左搜索框朝右、靠右朝左；中线迟滞避免抖动，单次开合方向固定且球锚点不跳。展开搜索栏搜索框高度 `36`，清零“×”采用 `28×28` 正圆小钮，“设置”按钮采用 `44×36` 圆角矩形（`CornerRadius=9`）与搜索框严格平齐。搜索结果、待操作预览上半屏向下、下半屏向上，空间不足换向或限高。
- M01-05：“悬浮球吸附到桌面边缘并自动隐藏”新配置/缺字段默认开启，已保存false保持。左右对称：贴边侧为矩形、朝屏内为半圆，绘制、毛玻璃、原生命中及内部命中一致，透明角不扩大；关闭恢复自由圆球。
- M01-06：开启吸附时，面板收起且鼠标离开2秒后隐藏，露出球宽1/4；展开、拖动、菜单或预览使用期间不隐藏。双向边缘位移动画100ms；移入露出区恢复完整球，不自动展开面板。关闭开关立即恢复自由圆球；保存位置不写边缘外坐标。无论是否开启边缘吸附，点击托盘或右键“隐藏悬浮球”后立即设置 `BallVisible=false`、停止边缘空闲定时器/边缘动画/展开动画、复位边缘隐藏态并彻底隐藏，后续菜单关闭、展开/收起看板、应用设置或定时器回调均不得反弹重新显示；点击托盘“恢复悬浮球”后正常恢复显示及当前展开态。
- M01-07：球数字只统计待操作内置身份的正式任务，排除草稿、自定义列表及其他身份；改名/隐藏不改统计，启动首显前刷新。零项隐藏，数字完整位于球内，多位缩小。边缘隐藏时用小红点替代数量气泡；红点总上移10DIP且与数量气泡边框同色，弹出开始渐隐。数字保留预布局，在红点完全消失的同一动画帧开始显示，不延后一帧、不重叠闪现；保持原100ms边缘位移动画及操作范围。后台提醒与监听不停。
- M01-08：球菜单总在球旁朝屏内展开，左右保留8DIP间距；靠上向下、靠下向上，四角结合且完整位于所在工作区，不遮球。托盘保留系统托盘位置，不跳到球旁。
- M01-09：主设置提供全局快捷键启用、录入、应用、恢复默认。默认Ctrl+~、无需Shift，按物理按键注册，不依赖输入法字符；按住不连发。失败/冲突提示且原快捷键可用，程序需保持运行。

## 验收与影响

分别操作自由球及吸附球的左右键、矩形角部、拖动、菜单；测试2秒隐藏、1/4露出、移入恢复、计数首显、后台更新、快捷键、整组恢复与托盘找回。鼠标测试按根AGENTS.md先询问用户是否方便，收到明确同意后才开始，使用隔离数据。窗口开合规则见[共享表面](SURFACE-背景动画与输入.md)，启动规则见[M12](M12-数据启动与交付.md)。
