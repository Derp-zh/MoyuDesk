# M09 搜索与阶段会话选择

现行规则，核对日期2026-11-13；任务搜索和会话目录搜索是不同功能。

- M09-01：展开球时搜索框朝屏内展开：球靠左向右、靠右向左，固定真实画布与100ms裁切保持，箭头光标、输入与光标可见。搜索正式任务名称及全部阶段详情，不搜索草稿/平台/优先级。结果靠上向下、靠下向上，空间不足换向或限高，超多滚动。
- M09-02：点击任务结果隐藏结果列表、定位正确列表及卡片并红闪两次，然后恢复原样，不改字段颜色。输入保留，X清输入及结果，面板收起也不自动清输入。搜索不替代六列数据。
- M09-03：编辑器阶段绑定会话胶囊保留原可用宽度（按旧状态图标加文字按钮宽度的1.6倍预算），不随新的24DIP状态圆按钮缩窄，显示会话名称，缺名显示未命名会话；单击打开绑定会话专属窗口；Codex原外部拖动操作保持；三平台均支持选择或拖到绑定窗口中对应平台的准确会话行。按名称包含匹配、忽略大小写，编号不参与搜索。结果及必要提示提供名称和编号，绑定窗右侧窄栏只显示本机已接入的平台；未安装或目录/运行时/配置检查失败的平台隐藏且不占位，已接入但客户端暂未运行仍保留本地目录。检查进行中保留最近已确定的展示状态；全部不可用显示设置初始化提示，禁止选择旧目录，已有绑定保持。普通操作单击切换，按住拖动时悬停180ms切换；切换只更换候选目录，侧栏不作为会话落点；目录分别只读本机SQLite、DSH元数据及Claude项目/事件元数据，不为列目录连接模型服务或联网；目录短期共享缓存，不新建聊天或发送消息。输入搜索不改绑定，可明确解除，选择／拖动结果先写编辑副本，保存后正式生效。
- M09-04：绑定会话专属窗口是父编辑／新建窗口右侧的小悬浮窗口，搜索框和会话列表常驻，移除列表收起／展开功能及箭头。选定会话后收起；父窗口关闭／隐藏后收起，下一次不自动打开。全程序最多一个，切换阶段时更新来源并清空搜索、隔离旧回调。普通及拖动均保持268×560的窄长窗口，会话列表200DIP约为原宽度的2/3，右侧40DIP平台窄栏用横线划成矩形，由可用平台平分高度，整块区域（含文字外空白）均可悬停切换，不用胶囊触发区；窗口打开时更新接入状态，当前平台失效自动回退可用平台；不再因拖动改变纵向尺寸；已开同窗不重放横向开窗，工作区较小时限制到可用高度。右侧不足翻到左侧，上下超屏限制到可用工作区，翻侧开合方向镜像。动画使用真实控件及可见范围，不采用截图交接。无常规说明行，空目录／失败保留反馈。
- M09-05：会话绑定属于具体阶段，旧任务级关联迁到原当前阶段，保留必要历史与代次；改绑/解绑重置实时保护并拒绝过时事件。会话目录可读不等于实时监听可用。列表名称布局见[M05](M05-阶段与卡片.md)。

基础PRD对任务搜索“忽略大小写”和悬浮预览400ms提出过建议，未将建议升级为新确认要求；本轮整理不改变现有匹配和延迟实现。

- M09-06：[X01拖动绑定](X01-拖动绑定探索.md)保留原编辑器搜索／选择／保存。在列表阶段会话名称或编辑/新建胶囊处拖到原Codex/DSH目标会话，松开绑定。Codex使用目标自己的“复制→复制深度链接”；DSH使用准确侧栏行自己的“复制 Session ID”，当前聊天区须唯一确认所属主会话。侧栏目标无需打开历史，不靠标题猜编号，不要求观察端口。DSH以返回编号核对本机目录名称；两平台的来源与编号不可混用。单击不改绑；失败保留原绑定，保存失败准确提示并保留可重试状态。DSH实现、本轮真实拖动验收及剩余边界见[C02](C02-DSH接入探索.md)和[0.9.38验收](../ACCEPTANCE-0.9.38.md)。

- M09-07：新建／编辑窗口胶囊拖动离开源悬浮窗口时，临时隐藏背后原可见多列表窗口，悬浮窗口保留；结束或取消仅恢复原可见列表，不改变整组展开标记。“自动打开会话绑定窗口”是可关闭的设置，默认开启，列表与编辑／新建均适用，拖到具体会话行松开绑定，或拖到窗口内原有“解除绑定”按钮区域悬停高亮并松手解除绑定（仅对已绑定阶段生效，未绑定阶段与快速新建不生效），空白／无效行不猜绑定。关闭此设置后不自动开窗；手动已开的绑定窗保持长高度，仍可作为拖动落点。
- M09-08：拖动前已打开的绑定窗在未执行、读取／保存失败或取消后恢复原打开状态、平台及搜索／选择／滚动；原平台已不可用则回退到可用平台，不恢复旧目录。成功（绑定或解绑）才收起。本次拖动才自动打开的窗口结束即收起。恢复不能覆盖新窗口、新数据或已关闭父窗口。正常父窗关闭／整组收起时子窗同步收起，不记忆打开状态；非拖动时点击父窗空白收子窗、点任务照常编辑、点其他应用照常收起整组，Esc只取消当前绑定或收起子窗，不新增Esc关闭父窗行为。具体实施与验证见[本轮记录](../DESIGN-CONVERSATION-UX-0.9.39.md)。

- M09-09：“跳转至会话”用于独立列表每个显示阶段及球待操作预览（当任务及所有阶段均未绑定任何有效会话时不显示）。按绑定平台和准确编号打开/激活相应客户端，按钮点击不打开任务编辑、不拖动整卡、不回答或批准。Codex使用原生codex://threads/UUID，保持当前进程；DSH核对登记程序/用户/Windows Session，先核对可访问候选行自己的Session ID，再选择同一元素；找不到时逐步展开分组及更多行，不凭标题决定身份。必要时只临时cloak本次看板窗口让出菜单，结束解除，不提交草稿或改变整组展开设置；剪贴板按原事务保护。未知编号、客户端不可用、用户新输入或来源变化明确反馈，原绑定不变。本轮支持Codex和DSH；Claude Code明确提示跳转未支持。点击跳转成功后收起所有看板窗口，仅保留悬浮球，程序和监听/提醒继续；失败时保持看板并提示，便于重试。收起不提交或丢失编辑及草稿，手动展开仍保留原输入。

跳转图标橙红仅代表该阶段绑定会话有尚未确认的待处理事件；时间提醒只显示红点。左键点击跳转至会话且跳转成功后，自动消除该阶段及绑定同一外部会话的其他阶段（#12联动）橙红提醒，卡片继续留在“待操作”列不变；跳转失败时不误消。手动移入进行中确认当前事件；右键单击阶段跳转图标仍可单独确认该阶段当前事件，恢复普通色，不移列、不跳转、不打开编辑或卡片菜单；多个阶段（同任务或跨任务）绑定同一外部会话时，确认、跳转成功或移回进行中后绑定该同一会话的其他阶段橙红同步消失，其他阶段不同会话橙红及时间红点不清。确认保留来源等待身份，旧事件跨轮询/重连/重启不反复提醒，新事件可重新提醒；真实执行清对应橙红，其他阶段待处理时整卡仍留待操作。后续新请求仍按准确事件重新提醒。

验收：真实字符/光标、隐藏阶段搜索、结果定位和红闪、清空/保留、向上空间、目录分页、搜索不改绑、选择后保存、卡片内外收起边界、失败反馈。连续按住鼠标悬停、矩形空白命中、短暂经过不误切、未接入平台隐藏/无占位、全断开/恢复与取消后绑定保护。跳转检查实际目标编号、仅一行高图标在正文内、未绑定禁用、多阶段橙红与恢复、球预览内按钮不触发外层定位；成功收起包含原本已收起看板时的待操作预览，仅留悬浮球，未保存输入保留。外部目录操作与控件测试分层记录。
