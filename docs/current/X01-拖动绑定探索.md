# X01 拖动绑定

现行操作适用于Codex和DSH，按准确原目标编号绑定，当前能力见[STATUS](STATUS.md)。

## 已确认需求

- X01-01：多列表独立窗口上，任务卡片的阶段会话名称成为可按住拖动的按钮；未绑定也提供入口。单阶段仍在既有名称位置，灵感库隐藏会话名和归档只读例外保持。
- X01-02：拖动预览显示来源名称及当前原Codex/DSH目标的会话名称，移开后不保留旧目标名称，预览只读且不作为最终身份；拖出来源列表窗口之前不隐藏其他列表，拖出后临时隐藏其他原可见列表，来源列保留。结束或取消只恢复原可见列表，不把原先隐藏的列表打开，不改变整组展开标记、正式配置和窗口位置。DSH外部松开后，菜单取号期间允许仅临时cloak本次来源窗口和绑定窗，finally解除且不触发WPF关闭或丢输入；Codex不走该分支。
- X01-03：在原Codex或DSH会话上松开应绑定到来源阶段，按目标实际平台保存。核心验收是原目标会话的真实绑定及准确编号落盘，不能以看板内目录拖动、隐藏/拒绑原型或菜单取号代替完整流程。Codex优先使用原会话菜单真实链接，不要求目标名称在目录匹配；DSH使用目标自身复制Session ID并按编号核对本机目录。名称不能成为唯一身份来源；当前聊天的多面板/来源歧义拒绝。DSH实现与验收边界见[C02](C02-DSH接入探索.md)、[0.9.38验收](../ACCEPTANCE-0.9.38.md)。
- X01-04：名称拖动不触发整卡移动或任务编辑；Esc在本次拖动期间记录并在松开前复核，快速轻按也取消；右键、丢失捕获、来源卸载或整组主动收起取消。单击不改绑定。普通整卡拖动、阶段开关、窗口背景/层次及原菜单位置保持。
- X01-05：确定编号后只改一个阶段，旧绑定保护和请求不继承；同编号名称更新不清保护。支持撤销，不提交现有编辑副本，不以旧编辑覆盖最新绑定。明确实际保存成功或失败。
- X01-06：测试数据独立；不向Codex或DSH投放文件/文字，不发消息、不回答/批准、不重启Codex。真实桌面测试前，按根AGENTS.md先询问用户是否方便并等待明确同意；仅开始前提示不能代替确认。此要求也覆盖切换前台及临时使用剪贴板。
- X01-07：优化保持“从阶段会话名拖到Codex或DSH目标、松开自动绑定”的原操作，不能用新增搜索／粘贴操作替代。释放时只做一次最终目标识别，沿用该元素取得原菜单真实链接；取链期间移动鼠标不取消。新点击／滚轮／Esc取消并保留原绑定，不吞输入、不固定鼠标。保持准确会话来源和原阶段保存／等待保护；开源实现用于指导自主实现，未经验证的输入封锁不加入普通路径。
- X01-08：拖动失败或目标未就绪时（含超时、前台变化、菜单未找到等）保留原绑定，并用通俗易懂的客服式文案解释可能原因及可操作建议；拖动期间允许拖到绑定会话专属窗口上的“解除绑定”按钮区域悬停高亮并松手解除绑定（仅对已绑定阶段生效，未绑定阶段与快速新建不生效并提示）。


## 实现与验收

ConversationBindingDrag管理拖动事务，CodexConversationDropTarget/DshConversationTarget只读目标预览，ConversationLinkResolver在松开后读取目标自身菜单返回的编号；ConversationClipboard完整缓存并按序号恢复，BoardController/BoardEngine处理绑定、撤销及保存。生产启动不注入示例或诊断。

验收覆盖真实目标和错误目标、名称外空白、单击/拖动分离、窗口恢复、Esc/点击/滚轮取消、过期结果、平台身份、改绑及同编号保护、编辑合并、保存失败和重试。原桌面拖动、离屏规则与原AI问答生命周期分开报告。历史版本探索和原回执仅在[旧版本更新日志](../history/CHANGELOG.md)追溯。
