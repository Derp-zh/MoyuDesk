# M08 平台、优先级及颜色

现行规则，核对日期2026-11-09。

- M08-01：界面统一称“平台”，默认codex淡紫色#C1A0EB、dsh（DeepSeek）蓝色#82AFF7、workbuddy绿色#77CBB0、Claude橙色#FFA773，多选；优先级默认紧急、重要不紧急、不重要不紧急，单选。两者都可不选，可新增、改名、改色、删除。标签不等于平台已接入。
- M08-02：选项管理在新建/编辑窗口内。选项右侧色彩按钮打开共用颜色选择器，只改颜色，不改变选择。支持24个常用色、最近12个已应用颜色、二维饱和度/明度色谱、色相滑杆、HEX（3或6位，可带#）和RGB（各0至255）输入、原色和新色预览；纯不透明RGB与现有数据一致。无效输入显示原因并禁用应用，暗色提示可读性但不擅自替换用户颜色。色谱可拖动，方向键微调、Shift加快；Tab切换，Enter应用、Escape取消。
- M08-03：颜色为候选，点击“应用颜色”后才提交；取消、Escape、外点关闭及原窗口收起均不提交。点击原色恢复本次候选。选项被删或数据源已切换时拒绝旧候选。应用后所有任务/选项胶囊同步，最近色去重并持久化。删除被引用选项后清空任务/草稿的选择，不强制替代。下拉首次点击展开、再点同一框收起，多选保持。
- M08-04：平台选项是分类或关联意图，新增Claude标签不自动安装或接入Claude。内部AiIds兼容，改名不丢关联。旧数据首次加载或导入配置时，只将名称和颜色均仍为旧默认的Codex绿、WorkBuddy紫升级为新默认；自定义颜色、选项编号和任务引用保留，仅补此前缺失的Claude。升级标记随偏好保存，用户之后删除Claude不会再次补回。旧JSON缺新字段可正常读回。

验收：多选/单选/空选、两处颜色入口、色谱与数值双向同步、无效输入、应用/取消/外点、最近颜色及重启回读；默认色/旧色升级/自定义与删除尊重；活动任务、归档和草稿引用保持，四档DPI和真实命中。颜色交互参考[Microsoft](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/color-picker)和[Adobe Spectrum](https://react-spectrum.adobe.com/v3/ColorPicker.html)，自主实现。实际接入见[C01](C01-Codex接入.md)和[M11](M11-设置与外部边界.md)。

依据：R50至R54/R54a、D08、U20/U29/U66，以及U08-0947本轮五项需求。
