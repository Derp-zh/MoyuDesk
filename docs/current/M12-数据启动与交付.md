# M12 数据、启动、配置及交付

现行规则，核对日期2026-10-21。

- M12-01：程序文件夹便携，默认持久任务为`%LOCALAPPDATA%/InstantTaskboard/data`、配置为同根`config`，均可编辑。更新程序目录不改变保存路径；程序搬走不等于系统数据自动随包搬走，启动/快捷方式/Codex环境/显示器也不会自动迁移。固定小型路径入口记录自选路径，任务不存注册表。
- M12-02：自动写入串行、临时文件刷盘、备份/原子替换；任务、全部非空草稿/未提交编辑、阶段、选项、提醒、布局、设置可恢复。损坏检查完整字段，保留原件，优先有效备份/恢复副本；已有数据与备份缺失不得静默建立空数据覆盖。失败信息必须可见。
- M12-03：切换任务数据目录前保存未提交内容；空目录复制当前数据，已有有效数据经界面确认才打开，不自动合并、不删原目录；同目录互斥。首次发现旧便携数据时复制迁移保留原件，正被使用拒绝，已有系统数据不覆盖/混合。正式迁移及`preserved-data`导入不由测试自动进行。
- M12-04：配置导出仅设置、布局、选项定义、路径记录和连接配置，不含任务/详情/草稿/提醒正文。导入不覆盖任务，保护列表/选项引用；无效外机路径保留当前并提示。旧含任务备份不可当配置包导入。任务文件的恢复配置副本与对外配置包分开。
- M12-05：每台电脑首次创建桌面快捷方式、默认自启，保留用户关闭自启的选择；设置可手动修复并实时诊断 `StartupApproved\Run` 禁用/路径失效状态。`--startup` 开机启动阶段对早期挂载/IO 瞬时异常自动平滑重试且多开/失败时不阻塞死弹窗。统一入口登记实际路径、版本、构建时间：最高存在版本优先，同版较新构建优先，旧版不降级。普通启动及启用自启更新入口，旧启动可转交已登记新版（透传 `--startup`）。不扫描全部快捷方式；登录实测与注册回读分开。
- M12-11：免管理员固定目录安装/升级/回滚与开源免服务器更新体系。每个便携包随 `Build-Portable.ps1` 自动附带 `version.json`、`安装或升级摸鱼台.cmd` 与 `scripts/install.ps1`、`rollback.ps1`、`uninstall.ps1`：默认安装至 `%LOCALAPPDATA%\MoyuDesk\app`，升级前仅平滑退出目标安装目录内旧进程、完整备份旧版至 `%LOCALAPPDATA%\MoyuDesk\.rollback-<oldVersion>` 并原子切换，桌面/开始菜单快捷方式及开机自启永久指向固定目录不断链，正式数据 `%LOCALAPPDATA%\InstantTaskboard` 永不修改；程序内 `AppUpdater` 直连公开 GitHub Releases API 检查新版，下载便携 ZIP 与 `SHA256SUMS.txt` 至 `%LOCALAPPDATA%\MoyuDesk\updates\` 并强制通过 SHA256 哈希校验与安全解压后拉起 `scripts/install.ps1` 完成平滑升级重启，并提供手动打开 GitHub 发布页兜底。
- M12-06：正式提交只合并用户改动字段，不覆盖后台新提醒/执行/运行标记；后台保存异步合并，单项变化增量更新，避免输入重建六列或同步写大文件。事件监听正确解除/不重复，隐藏停止无用高频更新。
- M12-07：性能目标为冷启≤2秒、常见响应≤0.2秒、300任务×4阶段/10草稿空闲平均CPU<1%、持续编辑100次无监听持续增长；属于验收目标，不写成所有设备保证。窗口真实裁切已接受繁忙掉帧，不能擅自恢复截图交接追求120帧。
- M12-08：普通修改不自动上传。用户明确要求更新GitHub时，同步源码、文档及对应 GitHub Release，提供包含 `MoyuDesk.exe` 的完整便携 ZIP 和 SHA256，核对远端及下载完整性。独立本地构建不覆盖正在使用的运行包，测试不修改正式自启。
- M12-09：AI初始化的首次提示决定、桌面/CLI路径和本机连接配置纳入现有原子配置保存/备份；失败可见，未保存不得显示初始化完成。重开后恢复配置并重新检查实时能力，不把历史成功当当前连接。保持任务/编辑合并与配置导入边界，不引入任务或聊天正文到配置。

- M12-10：每台电脑首次使用自动显示可跳过的五步新手浮窗，介绍悬浮球、记录任务、拖卡、可选AI及提醒；可上一步/下一步/完成，随时关闭或跳过，设置手动重看。记录独立保存在本机device/first-use.json，以机器身份识别，与应用版本、程序目录、任务/配置目录和备份分离；同机升级或换数据目录不重复。已有本机快捷方式/自启使用标记迁移为已用，避免老用户升级自动弹；异机可触发。记录加锁原子写入，损坏/写入失败保留原件并提示。首次教程等待AI初始化提示关闭后出现，不自动建任务或发AI消息。普通隔离测试不写系统记录。

验收：首次/同机换目录/升级/异机/旧机迁移、损坏和失败保留、跳过/完成/关闭/重看及AI提示次序，始终隔离`--data-dir`，断网保存/重启恢复、写入失败、损坏备份、路径空目录/已有有效数据/互斥、配置不含业务数据、跨窗口合并、启动登记防降级、发布下载。桌面鼠标测试按根AGENTS.md先询问用户是否方便，收到明确同意后才开始，不关闭用户进程或重启Codex。
