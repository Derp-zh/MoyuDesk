# M02 独立列表与布局

现行规则，核对日期2026-11-16。

## 有效规则

- M02-01：默认六个独立窗口，从左到右为灵感库、完善中、进行中、待操作、暂搁置、已完成，同时展开/收起，没有单列关闭按钮。内部角色与显示名称分开。默认内置进行中标题右侧提供“+”及右上AI角标的圆角矩形胶囊（仅此按钮局部模板，38×26DIP、7DIP圆角），按住拖动沿原准确绑定流程，一次有效落点按会话名称建立进行中任务并绑定；仅有效保存成功后建卡，取消、无效落点和保存失败不留空卡，已有活动任务或草稿绑定不重复创建。胶囊之外的标题仍可拖动窗口。设置“在所有列表标题显示 +AI”默认关闭，开启后全部内置及自定义独立列表复用同一按钮和原建卡绑定流程；创建的仍是进行中任务。
- M02-02：默认最大范围约屏宽7/8、工作区居中、避开任务栏；列间距24DIP，窄屏适当缩小间距、缩窄列但保持并排。默认宽高采用已确认的0.87比例及既定高度，标题区42DIP。已有用户手动布局优先，不因更新强制重排。
- M02-03：各列独立移动和拉伸，持久保存，不挤压邻列。顶部一行可左键拖动、无专用图形且指针不变；标题、菜单等实际控件不得被拖动区挡住。
- M02-04：单列菜单有“调整本窗口大小/结束调整”切换项，Esc及四边拖完同步结束；另有“本窗口恢复到默认”，只恢复该列在当前整组缩放基准下的尺寸和槽位。设置可统一显示/隐藏各列右下角缩放入口。开启后每个可见列表右下显示清晰青色斜线图标，18×18DIP整块底板可拖动；普通六列及专注两宽一窄均适用。
- M02-05：默认灵感库左下22×22DIP图案整块按住可同比缩放六列位置和大小，最大范围始终在工作区中央；松开结束并保存，不影响球、新建、编辑及设置。按住`Shift`键拖拽同一左下角入口可整体平移六列（及专注双宽一窄）最大范围框位置，平移限制在当前工作区边界内并持久化保存坐标与对应默认槽位。隐藏首列或进入专注模式后，整组入口归配置顺序的第一可见列，始终仅一处；启动及重启无需打开设置刷新才出现。两种尺寸入口均留在窗口圆角裁切内，保持原22×22/18×18整块可操作。球/托盘的“恢复窗口默认”及设置的“恢复窗口默认”恢复六列和球原始默认大小位置并重置组缩放，不改任务。
- M02-06：设置“窗口”管理列表数量、名称、新增、隐藏和删除。隐藏不计显示数量。六个内置列表均可改名/隐藏、不可删除；仅自定义列表可删除，含正式任务或非空草稿时仍不可删。旧配置中曾删除的完善中、暂搁置、已完成恢复为隐藏，保留原名称/身份，不强制显示。删除空自定义列表后撤销任务操作必须恢复原身份，配置导入保护任务列表引用。
- M02-07：列表根透明空白也属于完整交互面，保留空白右键、标题拖动、整组/单列缩放、卡片、新建、滚动条操作。虚线新建入口整块轮廓内部可点，不限于文字；入口在滚动内容末尾，不固定在底部。

- M02-08：Codex连接失败时，仅进行中/待操作两个内置角色窗口底部显示低调常驻状态文本，恢复消失；不按显示名称匹配，自定义同名列不显示。文字不抢输入，不替代滚动内容末尾的新建入口，其他拖动/菜单/缩放与布局保持。

- M02-09：设置“只看任务是否运行”默认关闭。开启后常态只显示内置进行中、待操作两个宽窗，不受角色改名影响；两宽窗及右侧已完成窄窗预先共同占用原可见列表最大范围，已完成隐藏时右侧留空。窄槽通常取范围宽19%，限制160至260DIP，剩余区域扣间距后由两宽窗等分。仅改变视图，不搬移其他任务。宽窗卡片自适应分列，从左向右逐行阅读，同一行按最高卡片留高；保留像素滚动、视口虚拟化和末尾新建，窄处退回单列。
- M02-10：待操作标题提供“已完成”勾选开关；开始拖动待操作卡片也自动向右展开已完成窄窗。完成只在预留槽开合，不遮挡、不挤压原窗；开合全过程原双窗的位置、尺寸、卡片宽度、列数和滚动位置不变。未勾选时，拖动待操作卡片仅临时展开，拖动成功、取消或无效落点结束后，保留450ms落点反馈再自动收起；新拖动取消旧收起计时。勾选后固定展开，拖动不控制开合，取消勾选则收起；勾选状态只代表手动保持。整组隐藏清理临时展开，保留手动保持。侧向100ms真实控件原生裁切、无泛光白条，快速反向接续。同一列表层内完成排在其他列前，编辑及设置层次保持更高。整组收起/恢复保留本进程展开决定，重启常态仍为两宽窗。
- M02-11：专注宽窗及完成窄槽分别保存独立位置；整组缩放同时缩放隐藏窄槽，普通列表显示、位置及组缩放基准不被覆盖。旧二窗/三窗专注几何不再用于当前执行，普通任务/配置兼容，关闭专注恢复普通布局。原来隐藏的专注内置角色可显示，但不改常规隐藏偏好；恢复整组默认清除专注位置。搜索定位完成时展开窄窗，定位其他隐藏列表任务时打开编辑，不改常规可见配置。

## 验收与边界

本轮另验默认三开关、全部标题AI、固定两宽一窄预留、开合零几何变化及非零滚动保留、多列拖动/取消/滚动/自动移列、完成手动保持/侧开/快速反向、隐藏改名自定义列表/两模式布局/配置重启恢复及真实系统与内部命中。分别验证单列/整组缩放和两种恢复基准、六个内置列禁删及隐藏/改名身份、旧删三列恢复隐藏、自定义非空删除拒绝、撤销恢复引用、空白右键和虚线内部角部。混合DPI、热插拔仍未全面验收。开合、背景及滚动见[共享表面](SURFACE-背景动画与输入.md)。
