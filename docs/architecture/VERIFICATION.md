# 按变更选择回归检查

涉及共享背景、命中、动画、输入或 AI 状态/保存链时，按以下要点执行回归检查。验证工具说明见 [ARCHITECTURE.md](../ARCHITECTURE.md)。

- **透明窗口与命中范围**：同时验证系统命中、内部控件命中和实际动作，覆盖文字外空白、边缘/角部（含圆角内收后的左下 `22×22` 与右下 `18×18` 缩放入口）、整块拖动区、右键菜单及按钮。列表共享层覆盖空白右键、标题拖动、灵感库左下整组缩放、单列缩放、卡片、新建全轮廓与滚动条；悬浮球覆盖左右吸附、拖动换边、搜索展开方向及菜单避让。
- **悬浮开合与背景稳定性**：分别验证打开、第一次外点、第二次保存/暂存、关闭开始与结束，包含编辑改动、关联区展开、正在保存及快速重开。普通开合全程使用真实控件裁切；最后一个草稿收起完成后才清理控件，快速重开取消旧清理。详见 [SURFACE-背景动画与输入.md](../current/SURFACE-背景动画与输入.md)。
- **AI 监听状态、多阶段聚合与保存链**：回归跨重连多阶段等待优先、旧终态隔离、解绑重绑/归档恢复、编辑合并及红点。已确认的等待状态不因 `Unknown` 或其他阶段运行而丢失，新绑定不继承旧保护；只有真实恢复执行且整卡回到“进行中”才清除阶段等待提醒（手动移入进行中只确认当次等待事件，同轮后续新请求仍提醒；右键跳转图标仅确认当前提醒）。详见 [C01-Codex接入.md](../current/C01-Codex接入.md)。
- **自动建卡与主侧会话**：未绑定会话自动建卡默认关闭；开启时检查历史基线隔离、任务/草稿去重、先落盘后插卡、主侧会话归并以及单会话错误隔离。
- **提醒、完成窄窗与教程**：提醒编辑器验证日期/时间输入与合法值分离、日历选择、取消不提交及原调度；专注模式完成窄窗分别验证勾选固定展开与拖卡临时展开；新手教程验证本机首次记录与升级不重弹。
- **实测边界诚实记录**：目录读取、后台日志、前台控件、真实客户端问答往返与落盘结果分别报告；模拟夹具不冒充原客户端完整生命周期验收。
