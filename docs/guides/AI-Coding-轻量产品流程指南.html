      把这些词翻译成人话
      Skill 和 CLI 有什么不同？
      Skill 是教 AI 按某种方法工作的操作手册；CLI 是能通过命令调用的工具。lark-base 教 AI 怎样操作多维表格，执行操作的是 lark-cli。
      MVP：第一版做到什么程度？
      能完成核心使用流程的第一版产品。功能可以少，但核心操作、数据保存和错误处理要可靠。
      本地优先：为什么操作会更流畅？
      先读取和保存电脑上的数据，再在后台与飞书同步。列表操作不需要等待网络，但必须设计同步失败和冲突的处理方式。
      原型和成品有什么不同？
      原型主要验证界面和操作方式，可以使用演示数据；成品还要验证真实保存、同步、状态监听、打包和恢复。
      Git 和数据备份有什么不同？
      Git 是代码的存档点，方便回到之前的程序版本。用户任务数据需要单独备份，并验证能够恢复。
      双向同步：最难的是什么？
      两端同时修改同一任务、断网重试和删除传播。如果只做上传和下载，可能覆盖修改、生成重复任务，或让已删除任务重新出现。
