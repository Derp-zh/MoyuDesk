# Git使用说明

Git保存的是已提交的项目文件版本。未提交文件和被忽略的数据不在该次提交中，提交也不能替代个人任务数据备份。

本工作区的根Git仍是旧本地master，当前生产源码与历史提交并非自动同步。接手时先运行`git status --short`、`git branch --show-current`、`git remote -v`核实，再决定本轮需要提交的文件。不要按旧教程使用git add -A，不把当前工作树整体推上远端。

现行源码、规则和验证入口见[项目索引](docs/INDEX.md)。正式任务、配置、认证、聊天、本机索引、test-output、运行包及preserved-data不进入源码提交。提交前审查实际文件清单和差异，不能只凭.gitignore断言已排除所有资料。

本地修改不等于已提交，已提交不等于已上传；程序包也不等于源码。只有本轮明确授权发布时才按[发布约定](GitHub上传教程.md)继续。

早期教程的固定提交号、大小和环境状态只作[历史原文](docs/history/20261107-integration/Git使用说明.md)追溯，不作为当前操作依据。
