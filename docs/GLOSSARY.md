# 摸鱼台 · MoyuDesk

本词汇表记录用户确认的正式名称，供界面、需求和后续沟通统一使用。

## 监听模块

**AI平台监听**：围绕AI平台会话开展绑定、状态读取及任务状态联动的一类模块。包括Codex监听、DSH监听、Claude监听等。
_Avoid_：用未限定平台的“通知监听”指代AI会话状态读取。

**Codex监听**：AI平台监听中的Codex模块，涵盖绑定会话、读取会话状态和自动移列等功能。
_Avoid_：Codex接入模块、Codex通知监听。

**DSH监听**：AI平台监听中的DeepSeek Harness模块，涵盖会话绑定、状态读取和自动移列。

**Claude监听**：AI平台监听中的Claude Code模块，涵盖会话绑定、状态读取和自动移列。
_Avoid_：将普通Claude网页聊天称作Claude Code会话。

**通知监听**：Windows系统通知的监听及相关提示音功能，与AI平台监听分别归类。
_Avoid_：用未限定范围的“监听”同时指代这两类模块。

## 窗口与提示

**绑定会话专属窗口**：用于搜索、列出和选择待绑定会话的小悬浮窗口。
_Avoid_：用编辑窗口内的“下拉列表”称呼新的独立窗口。

**自动打开会话绑定窗口**：拖动绑定会话过程中自动打开绑定会话专属窗口的可选功能名称。

**提示气泡**：呈现短时操作反馈的提示，包括绑定结果和至少保留一个运行阶段的提示。
_Avoid_：将操作提示气泡与Windows通知混称。

**细分设置**：设置窗口内的各个具体页面，例如主设置页、归档页。
